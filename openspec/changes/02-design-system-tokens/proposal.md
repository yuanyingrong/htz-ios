# Proposal: Design System Tokens

## Goal
Establish a unified visual language by defining design tokens (Color, Typography, Spacing, Radius) in the `DesignSystem` module.

## Change
- Add `Tokens/` directory in `DesignSystem` SPM package.
- Define SwiftUI extensions for `Color` and `Font`.
- Implement basic `Spacing` and `Radius` enums.
