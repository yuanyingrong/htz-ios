- [x] 1.1 `AudioEngine` 增加 `seek(to:)`、`setRate(_:)`，播完时发出可观察的结束状态。
- [x] 1.2 `PlayerItem` 增加 `sutraId`；`PlayerState` 增加 `rate`。

- [x] 1.6 接入 `MPNowPlayingInfoCenter` 和 `MPRemoteCommandCenter`（播放、暂停、上下集、拖动）。
- [x] 1.7 下载并解析原文 LRC，按播放时间高亮；可切换到讲解歌词。
- [x] 1.8 切集和暂停时上报 `POST /post/listen/history`，失败不打断播放。
- [x] 1.9 为入队、上下集、播完自动下一集、付费拒绝不切歌补 reducer 测试。
